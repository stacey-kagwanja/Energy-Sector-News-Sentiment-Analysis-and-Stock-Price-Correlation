# Energy-Sector-News-Sentiment-Analysis-and-Stock-Price-Correlation
This was a Python group project, with the aim of analysing how news sentiment affects energy sector stock prices. We analysed the correlation between news sentiment and energy stock prices and used natural language processing to create an LSTM model that derives the sentiment signal of headlines.

To install the required Python libraries, after downloading all of the files, run the following command in your terminal or command prompt:
  pip install -r requirements.txt
